# KUN Infra Pvt Ltd – Official Single-Page Website

A clean, modern, responsive single-page corporate website designed and built directly from the **KUN Infra Pvt Ltd** brand identity, logo, and leadership specifications.

---

## 🎨 Brand Color Palette (Derived Directly from Logo)

The visual design system is anchored in the metallic gold, deep royal navy, and warm ivory tones sampled directly from the brand logo:

| Token Name | Hex Code | Role in Design |
| :--- | :--- | :--- |
| `--color-primary-navy` | `#092347` | Primary brand typography, dark cards, and headings |
| `--color-primary-dark` | `#041124` | Midnight luxury slate for footer & hero contrast |
| `--color-gold-base` | `#C59A27` | Primary metallic architectural gold from towers |
| `--color-gold-light` | `#E5BF4C` | Golden pillar highlight and accent icons |
| `--color-gold-dark` | `#8C6811` | Burnished architectural bronze for borders/badges |
| `--color-bg-ivory` | `#FBFBF9` | Warm ivory paper background from logo card |
| `--color-surface` | `#FFFFFF` | Elevated card surfaces and navigation |

## 🚀 How to Run Locally

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates an optimized production build in the `dist/` directory.

### 4. Preview Production Build
```bash
npm run preview
```

## 🛠️ Tech Stack
- **Framework:** React 18 + Vite 5
- **Icons:** Lucide React
- **Typography:** Cinzel (Regal Architectural Serif) & Plus Jakarta Sans (Modern Geometric Sans)
- **Styling:** Custom CSS Variables, Glassmorphism, Micro-interactions, Responsive Breakpoints
